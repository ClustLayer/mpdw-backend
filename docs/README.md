# Documentación MPDW Backend

| Carpeta / archivo | Contenido |
|-------------------|-----------|
| `qa/` | Casos QA por épica y cierre de sprint |
| `fixes/` | Notas de corrección por iteración (`correcciones-iteracion-*.md`) |
| `guides/` | Guías operativas, estructura de código, historias de usuario y reportes |
| `openapi.yaml` | Contrato REST (regenerar con `manage.py spectacular`) |

## Convención de nombres

- **QA:** `qa/epic-N.md`, `qa/qa-epic-N.md` (legacy Sprint 2), `qa-sprint*.md`
- **Fixes:** `fixes/correcciones-iteracion-N.md`; post-épica 9 ver `fixes/correcciones-iteracion-14-epic9-pos-ventas-domicilios.md`
